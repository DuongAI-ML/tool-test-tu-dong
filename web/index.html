    Các cột trong file Excel = các cột đang tick ở Cài đặt › Cột báo cáo.

    Tick cột nào thì cột đó có trong file mẫu và file báo cáo. Có thể đổi tên cột cho giống file của bạn — khi đọc file, tool nhận cột theo cả tên mặc định, tên bạn đặt và các tên thường gặp (VD "Kết quả mong đợi" = "Expected result"). Kéo ↑↓ để đổi thứ tự.

    Thư mục dữ liệu của tool:

    Dùng nhanh trong 4 bước

    1. Viết test case trong Excel — sheet TestCase, mỗi bước một dòng. Dòng đầu của TC ghi TC ID và thông tin chung; các dòng bước sau để trống TC ID.
    2. Ở mỗi bước, điền thêm 3 cột cho tool chạy: Hành động (chọn trong danh sách bên dưới), Đối tượng (ô/nút cần thao tác), Giá trị. Bước nào bỏ trống Hành động = test tay.
    3. Mở file trong tool → tick các TC cần chạy → bấm Chạy test. Case test tay / bán tự động: tool sẽ dừng lại và hỏi bạn Pass/Fail.
    4. Tab Kết quả & Xuất file → đặt tên file → Xuất file Excel.

    Cách ghi cột Đối tượng

    • Ghi như người đọc: Ô Email, Nút "Đăng nhập", Link "Quên mật khẩu", Dropdown Phòng ban, Checkbox Ghi nhớ, Tiêu đề "Đơn hàng". Tool tự tìm theo nhãn, placeholder, chữ trên nút…
    • Nhiều phần tử giống nhau: thêm #2 để lấy cái thứ 2 — VD Nút "Xóa" #2.
    • Phần tử khó tìm: đặt tên trong sheet Elements (Tên → selector CSS/XPath), rồi ghi tên đó vào cột Đối tượng. Hoặc ghi thẳng selector: #email, css=table tr, //button[1].

    Biến

    • ${base_url}, ${user}… lấy từ sheet Env theo môi trường đang chọn.
    • Cột Test data ghi email=a@b.vn; sdt=0901234567 → dùng ${email}, ${sdt} trong TC đó.
    • Có sẵn: ${ngau_nhien} (số ngẫu nhiên, giữ nguyên trong 1 TC), ${hom_nay}, ${demo_url}. Bước lưu_text lưu chữ trên trang thành biến.

    Kích thước màn hình / trình duyệt

    Cột Kích thước màn hình: 1920x1080, 768x1024, 375x812 hoặc desktop, tablet, mobile → TC chạy lại ở từng kích thước. Cột Trình duyệt: Edge, Chrome.
